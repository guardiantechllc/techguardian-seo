# Tech Guardian Goals 2026

## Quick Import to Google Sheets

1. Go to [Google Sheets](https://sheets.google.com)
2. Create a new spreadsheet
3. File > Import > Upload > Select `tech_guardian_goals_2026.csv`
4. Choose "Replace current sheet" and click Import

## Goal Categories Overview

### REVENUE (4 goals)
- **25% monthly revenue increase** - Track via Square POS
- **2 new high-margin service lines** - Premium data recovery, B2B contracts
- **15% parts cost reduction** - Bulk pricing, better suppliers
- **40% profit margins** - Pricing review, eliminate low-margin services

### MARKETING (4 goals)
- **SEO: Rank #1 for iPhone repair KC** - Landing pages, reviews, backlinks
- **50 leads/month digital** - Google Ads, Instagram, TikTok
- **30% walk-in increase** - Partnerships, flyers, events
- **Personal brand building** - Podcasts, articles, speaking

### TEAM (4 goals)
- **Hire 1 technician** - Focus on console/PC skills
- **20% faster repair times** - SOPs, tracking, organization
- **95% customer satisfaction** - Surveys, review response
- **Leadership development** - Courses, 1:1s, feedback

### OPERATIONS (4 goals)
- **Inventory management system** - RepairDesk or similar
- **90% same-day completion** - Track and improve bottlenecks
- **Standard Operating Procedures** - Document everything
- **Owner off repairs** - Delegate to team, focus on business

### CUSTOMER EXPERIENCE (3 goals)
- **Booking system** - Square Appointments
- **Loyalty program** - Punch card, referrals
- **Better communication** - Text updates, status tracking

### PERSONAL DEVELOPMENT (4 goals)
- **Work-life balance** - 50 hr/week max, vacations
- **Financial planning** - Emergency fund, accountant
- **Health** - Exercise, checkups
- **Learning** - Certifications, conferences, books

### GROWTH (3 goals)
- **Second location research** - Demographics, financials
- **Mobile repair service** - Van, expanded service area
- **Exit/succession planning** - Documentation, valuation
